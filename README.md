# GymMate – Fitness and Expense Tracker

GymMate is a web-based fitness and expense tracking system designed to help users manage their workouts, daily steps, fitness goals, expenses, and diet planning in one place.

## 🚀 Features

- 🔐 User Registration and Login
- 🏋️ Workout Tracking
- 👟 Step Tracking using Google Fit API
- ❤️ Fitness Activity Tracking
- 🎯 Fitness Goal Setting and Progress Tracking
- 📊 Workout and Calorie Analysis
- 💰 Expense Tracking
- 🤖 AI Diet Planner
- 👥 Community Updates
- 👨‍💼 Admin Dashboard

## ⚙️ Installation

### 1. Clone the repository

git clone https://github.com/YOUR-USERNAME/GymMate.git

### 2. Install Backend Dependencies

cd backend
npm install

### 3. Install Frontend Dependencies

cd ../frontend
npm install

### 4. Configure Environment Variables

Create a `.env` file inside the backend folder and add your required configuration.

Example:

PORT=3001
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=GymMate

Do not upload your `.env` file to GitHub.

### 5. Run Backend

cd backend
npm start

### 6. Run Frontend

cd frontend
npm start
